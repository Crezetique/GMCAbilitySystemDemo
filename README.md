# GMC Ability System Demo

Prerequisites:
- GMC Demo *(Download from GMC Discord)*
- [GMC Ability System (GMAS)](https://github.com/reznok/GMCAbilitySystem)

Installation:
- Both GMC Demo and GMAS Demo should be added to your Unreal Engine project's `../Plugins/` folder.
  - /ProjectRoot
    - /Plugins/
	  - /GMCAbilitySystemDemo
	  - /GMCv2_Demo
